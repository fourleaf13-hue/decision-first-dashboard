# Historical engineering records

The files in this directory are historical planning and implementation records. They capture design decisions, hypotheses, and migration steps at the time they were written.

They are **not the current product contract** and may describe superseded architecture, terminology, or implementation boundaries.

For current behavior and authority, use the production skill and its executable contracts:

- `skills/decision-first-dashboard/SKILL.md`
- `skills/decision-first-dashboard/schemas/`
- `skills/decision-first-dashboard/scripts/`
- `skills/decision-first-dashboard/references/`
- repository tests under `tests/compiler/`

When a historical plan conflicts with those sources, the current executable contracts win.
